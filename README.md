# Mota Intranet + CRM

Portal interno + CRM jurídico da Mota & Advogados. Next.js 15 + TypeScript + Prisma + Postgres + Auth.js Google (hd=mota.adv.br) + Tailwind. Design system Mota (navy + gold, glassmorphism).

## Deploy
1. `git push` para carlosslack/mota-intranet-v2
2. GitHub Actions publica `ghcr.io/carlosslack/mota-intranet-v2:latest`
3. Hostinger reinicia o compose apontando pra `intranet.motaadv.net`
